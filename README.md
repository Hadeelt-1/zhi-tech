# ZHI TECH

صفحة ويب ثابتة (HTML/CSS) لمشروع ZHI TECH. المشروع في مرحلته الأولى: الهيكل الأساسي وتذييل الصفحة جاهزان، والصفحة الرئيسية ستضاف لاحقًا.

A static HTML/CSS website for ZHI TECH. The project is at an early stage: the base layout and footer are done, and the main page content is coming soon.

## الملفات | Structure

```
zhi-tech/
├── index.html   # الصفحة الأساسية | main page
├── style.css    # التنسيقات | styles
└── README.md
```

## التشغيل | Run locally

لا يحتاج المشروع إلى أي تثبيت. افتحي `index.html` في المتصفح مباشرة، أو شغّلي خادمًا محليًا:

```bash
python3 -m http.server 8000
```

ثم افتحي http://localhost:8000
